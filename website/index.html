05 · MCP reality

Model Context Protocol is the new perimeter

Everyone is wiring agents to tools. Few are red-teaming that wire. THE VOID treats MCP as first-class: scan it, attack it, chain it, beacon through it — and ship defensive MCP tooling under mcp-tools/.

A

MCPAttack

Enumerate tools, auth posture, attack-class patterns, CVE-shaped findings on MCP servers.

C

MCPChain

Compose findings into multi-step DAGs. Detect cross-server cascades before they become surprises.

2

MCPC2

Post-ex C2 that blends into legitimate tool traffic. Beacons in. Tasks out. Health checks. Rotation.
